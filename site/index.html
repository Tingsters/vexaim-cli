THREE SMALL STEPS

From download to robot

  1. Extract your download

    Each bundle includes the executable, a matching vex-aim skill, and installers. Verify the archive against SHA256SUMS before running its files: Get-FileHash -Algorithm SHA256 <archive> on Windows; shasum -a 256 <archive> on macOS/Linux.

  2. Run the installer

    Open a terminal in the extracted folder.

    Windows PowerShell

    powershell -ExecutionPolicy Bypass -File install.ps1

    macOS / Linux

    sh install.sh

    No Rust or Python packages needed. The extracted bundle installs offline. The robot can be off. Your agent's settings stay unchanged.

  3. Start a new agent session

    Goose, Codex and Claude Code can discover the installed skill. Connect and switch on your robot, then try this:

    Use the vex-aim skill. Connect to my VEX AIM over USB, report its battery, and set its lights blue for two seconds. Do not move it.

    For wireless access, ask for Bluetooth and give your robot's exact name. The skill guides your agent through pairing and connection reuse.

Prefer a terminal?

Run the executable from the extracted folder, or use its full path under your installed skill's bin/ directory.

vexaim doctor
vexaim info
vexaim snap -o photo.jpg

On PowerShell use .\vexaim.exe. More examples →

A simple connection

No saved robot project, firmware changes or special Wi-Fi. Photographs are saved locally. Clear the floor and keep someone near the power switch before movement.

All four platforms are built and installation-tested in CI. Windows USB/Bluetooth and earlier Linux USB have real-robot evidence. macOS hardware and the newest movement helpers need further hardware verification.
