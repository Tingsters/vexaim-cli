Install for your computer

Paste one command into your terminal. It downloads and installs the latest stable executable and matching vex-aim agent skill. No clone, extraction, compiler or administrator access needed.

Windows

PowerShell 5.1 or newer · x86_64

irm https://raw.githubusercontent.com/Tingsters/vexaim-cli/main/install.ps1 | iex

macOS

Terminal · Apple Silicon or Intel

curl -fsSL https://raw.githubusercontent.com/Tingsters/vexaim-cli/main/install.sh | sh

Linux

Terminal · x86_64

curl -fsSL https://raw.githubusercontent.com/Tingsters/vexaim-cli/main/install.sh | sh

The installer verifies the release archive's SHA-256 checksum and installs for Goose/Codex and Claude Code. The robot can be off. Rerun the same command to update after closing robot sessions. Linux USB may later need an approved udev rule.

Release notes · SHA-256 checksums

Manual or offline installation

Download the bundle for your computer above and verify it against SHA256SUMS: use Get-FileHash -Algorithm SHA256 <archive> on Windows or shasum -a 256 <archive> on macOS/Linux. Extract it, open a terminal in that folder and run:

Windows PowerShell

powershell -ExecutionPolicy Bypass -File install.ps1

macOS / Linux

sh install.sh

The extracted bundle installs offline. Start a new agent session afterward.

Prefer a terminal?

Run the executable from the extracted folder, or use its full path under your installed skill's bin/ directory.

./vexaim doctor
./vexaim info
./vexaim snap -o photo.jpg

On PowerShell use .\vexaim.exe. More examples →

A simple connection

No saved robot project, firmware changes or special Wi-Fi. Photographs are saved locally. Clear the floor and keep someone near the power switch before movement.

All four platforms are built and installation-tested in CI. Windows USB/Bluetooth and earlier Linux USB have real-robot evidence. macOS hardware and the newest movement helpers need further hardware verification.
